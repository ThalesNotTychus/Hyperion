Windows 下同时登录多个 Claude Code、Codex 与 Antigravity（反重力）账号防串号完整指南

重度使用 AI 编程智能体（Claude Code、OpenAI Codex、Google Antigravity 反重力）的开发者，几乎都踩过同一个坑：手头有 2～3 个 Pro/Max/Team 订阅账号想轮换使用，但在同一台 Windows 电脑上一旦在第二个终端执行登录，第一个窗口的会话令牌立刻被覆盖失效，甚至触发异常风控。

一、为什么同平台多开在 Windows 上一定会「串号」？

三大主流编程智能体在默认情况下都会读写当前系统用户的全局单例目录与系统凭据管理区：

智能体平台默认冲突位置（串号根源）官方合规物理隔离环境变量
OpenAI Codex%USERPROFILE%\.codex 与 Electron 默认 UserDataCODEX_HOME + CODEX_SQLITE_HOME + --user-data-dir
Claude Code%USERPROFILE%\.claude 与全局 API 环境变量CLAUDE_CONFIG_DIR + 独立隔离 USERPROFILE
Google Antigravity%USERPROFILE%\.gemini 与默认凭据命名空间ANTIGRAVITY_GEMINI_DIR + ANTIGRAVITY_CREDENTIAL_SCOPE + 官方 agy acp

二、手动 PowerShell 隔离 vs Hyperion 进程级自动沙箱

如果只靠手动写脚本启动，不仅每次开终端都要重新设置一整套环境变量，还很容易因为父进程残留的 OPENAI_API_KEY 或 ANTHROPIC_API_KEY 导致计费串台。例如标准的 Claude Code 独立号隔离需要：

$env:CLAUDE_CONFIG_DIR = "D:\AgentProfiles\claude-pro-2\.claude"
Remove-Item Env:ANTHROPIC_API_KEY -ErrorAction SilentlyContinue
claude

为了彻底消除手动切目录的繁琐并做到 100% 零封号风险（绝不读取或复制官方 auth.json / OAuth 令牌），开源工作台 Hyperion 在底层直接实现了按子进程物理隔离的账号池与内置 ConPTY 伪终端：

  • 每个账号独立物理沙箱目录：新建「账号 2 / 账号 3」后，在内置分屏终端一键打开该账号专属登录环境，授权一次永久独立保存，多个账号可在同一个聊天室里用 @账号1 @账号2 同时干活。
  • 反重力官方标准 agy acp 直连：严格通过 Google 公开的 Agent Client Protocol 标准协议通信，本机已有登录态可直接免扫码复用；需要双开时也可一键接入免客户端 Gemini 直连 API（Windows DPAPI 硬件加密密钥），从根源杜绝 Google 账号串号。
  • 电池级实时余量监控：直观查看各账号 5 小时与 7 天剩余额度百分比，不用再盲猜哪个号快见底。

三、三步配置多账号同屏协同

  1. 前往 GitHub Releases 下载 Hyperion-portable-win-x64.zip，解压双击 Hyperion.exe（单文件免安装，零 Node.js 依赖）。
  2. 点击左侧「账号池 → ＋添加账号 / Agent」，按需添加隔离 CLI / 桌面实例，或直接填入 OpenAI / Claude / Gemini / DeepSeek API Key。
  3. 打开你的代码仓库目录，直接回车用默认主力号编码，或输入 @ 同时召唤多个不同平台智能体交叉评审！
