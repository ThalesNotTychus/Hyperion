ARCHITECTURE & CAPABILITIES

直击多智能体高频研发的六大痛点

拒绝套壳浏览器与臃肿运行时，用纯正的 .NET 10 原生进程编排解决多开串号、限流中断与代码冲突。

🛡️

进程级多账号物理防串号

按子进程严格隔离 CODEX_HOME、CLAUDE_CONFIG_DIR、USERPROFILE 与 ANTIGRAVITY_CREDENTIAL_SCOPE，同一台 Windows 电脑同时跑多个同平台账号永不互相顶替会话。

⚡

5h / 7d 电池配额与 429 自动接力

通过官方只读接口实时展示 5 小时与 7 天剩余配额百分比及重置倒计时；任务途中触发限流或超阈值时，自动切换池内健康备用号在同一分支无缝继续。

🔌

官方标准 agy acp 零封号免重登

严格遵循 Google 公开的 agy acp (Agent Client Protocol) 标准协议通信，自动检测或静默部署官方 CLI，100% 直接复用桌面端已有登录态，无需重复扫码登录。

🌿

一键 Git Worktree 赛马与行级打回

同一需求可一键派生 2～6 个独立 Git Worktree 分支并行编码并自动执行测试验收；内置 Unified / Split 并排 Diff 抽屉，支持点击任意代码行写批注打回返工。

🧰

免下载内置 C# Agent 工具链

无需安装数 GB 桌面端，填入任意 OpenAI / Claude / Gemini / DeepSeek / OpenRouter 密钥或本地 Ollama 地址，即自动赋予沙箱文件读写与无窗命令执行能力。

🎯

双 WebView2 网页点选 + 原生 ConPTY

分屏实时预览本地前端页面，点选任意 DOM 元素即可自动提取选择器、计算样式与视口截图带入对话；底部内嵌 Windows 原生伪终端，支持四套皮肤与中英双语。

三步开启多智能体协同研发

单文件自包含发布，不污染系统注册表与全局环境变量。

STEP 01

下载解压，双击即用

下载 Hyperion-portable-win-x64.zip 解压至任意目录，直接运行 Hyperion.exe（开源未商业签名版首次打开如遇蓝框提示，点「更多信息 → 仍要运行」即可）。

STEP 02

自动识别已有账号或接入 API

自动发现本机已登录的 Codex、Claude Code 与 Antigravity 账号（直接免重登复用），也可在「＋添加账号」中填入任意 API Key 或本地 Ollama 模型。

STEP 03

动态选模、@ 协同与 Worktree 赛马

打开任意项目文件夹，在底部随时切换具体模型与思考深度（Low ～ Max），输入 @ 呼叫多账号配合，或切入「竞技场」让多模型在独立分支同台竞技。
