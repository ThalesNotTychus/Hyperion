Hyperion is a single-file native Windows IDE workspace that physically isolates multiple AI coding subscriptions per process, monitors live 5h/7d battery quotas with automatic HTTP 429 failover, and races 2–6 models in parallel Git Worktrees with inline Split-Diff review.

⬇ Free Download for Windows 10/11 (x64) View Source on GitHub Community & Guides

🛡️ Physical Multi-Account Isolation

Isolates CODEX_HOME, CLAUDE_CONFIG_DIR, USERPROFILE, and ANTIGRAVITY_CREDENTIAL_SCOPE per child process so multiple Pro/Max/Team accounts run side-by-side without overwriting tokens.

⚡ Live 5h/7d Quotas & Auto-Failover

Reads official 5-hour and 7-day remaining quota windows. Automatically switches to a healthy backup account or fallback API in the same Git worktree on HTTP 429 rate limits.

🔌 Official Google Antigravity ACP

Communicates strictly over Google's public Agent Client Protocol (agy acp JSON-RPC 2.0 over stdio), reusing existing sign-in state with zero ban risk.

🌿 Parallel Git Worktree Arena

Benchmark 2–6 models (or multiple models on one API key) in isolated Git worktrees, run automated verification tests, review Split Diffs line-by-line, and merge the winner.

🧰 Zero-Download Built-In Agent Loop

Connect OpenAI, Anthropic, Gemini Native, DeepSeek, OpenRouter, or local Ollama with built-in CRLF-preserving edit_file, search_files, multimodal vision, and DPAPI hardware encryption.

🎯 Dual WebView2 Visual Inspector

Preview local web apps side-by-side, click any live DOM element or paste clipboard screenshots directly into multimodal agent prompts, paired with an integrated Windows ConPTY terminal.

Frequently Asked Questions

How do I use multiple Claude Code or Codex subscriptions on one Windows PC?

Add isolated profiles in Hyperion's Accounts Pool. Each profile gets its own dedicated CLAUDE_CONFIG_DIR or CODEX_HOME sandbox — sign in once in the integrated ConPTY terminal and collaborate across @Agent1 @Agent2 in one thread.

Does Hyperion read, copy, or proxy official OAuth tokens (auth.json)?

Never. Official CLIs manage their own authentication inside isolated directories, and Direct API keys are encrypted locally with Windows DPAPI (CryptProtectData).

What happens when an account hits a 5-hour quota limit (HTTP 429) mid-task?

With Auto-Failover enabled, Hyperion places the rate-limited account into cooldown and seamlessly continues your conversation on the healthiest same-engine backup account or Direct API fallback without losing context.
